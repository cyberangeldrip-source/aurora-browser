# Aurora 1.6.0

## Сводка для продолжения работы

- Aurora работает на Rust, Tauri и WebView2. Исходники и сборки Windows x64 публикуются в [репозитории Aurora](https://github.com/cyberangeldrip-source/aurora-browser).
- Основной каталог данных профиля совместим с выпусками 1.5.0. История переносится из прежнего JSON в SQLite при первом запуске 1.6.0. Остальные данные загружаются с прежних путей.
- Интерфейс использует реальные значки сайтов, стеклянные меню и плавное перемещение вкладок. Фон стартовой страницы анимирован.

## Что сделано в 1.6.0

- Под адресной строкой появилась панель закладок со значками, горизонтальной прокруткой и меню папок. Её можно скрыть в настройках.
- Списки выбора, ползунки, флажки, карточки и подсказки Aurora получили стеклянное оформление. На актуальном WebView2 оно охватывает раскрывающиеся списки настроек и выбора браузера.
- Добавлен раздел «Профили и пароли». Новые локальные профили открываются в отдельных окнах со своими настройками, данными сайтов, сеансом и хранилищем входов. В списке паролей доступны поиск, добавление, замена и удаление записи.
- История хранится в SQLite. Обычная навигация записывает отдельное посещение, а массовые изменения сохраняются транзакцией.
- Импорт Chromium и Firefox сохраняет путь папки закладки и метку группы вкладок при наличии соответствующих метаданных. Вкладки одной группы отмечены общим цветом.
- Раздел плагинов управляет распакованными расширениями WebView2 и локальными CSS/JavaScript-плагинами. Для локальных плагинов доступен список точных доменов. Разрешения WebView2-расширений задаёт их manifest.json.
- Автоматический тест проверяет преобразование истории из 50 000 посещений и инкрементальную запись следующего посещения. GitHub Actions проверяет форматирование, тесты, Clippy и сборку Windows.

## Следующие обновления

- Добавить сворачивание и ручное управление группами вкладок, а также редактирование структуры закладок.
- Расширить тестовую матрицу импорта HTML, Firefox и сторонних Chromium-сборок, проверить интерфейс на нескольких GPU, версиях WebView2 и масштабах Windows.
- Добавить управление выданными разрешениями расширений и интерфейс действий расширений. Текущий выпуск устанавливает их из распакованных папок.
- Спроектировать отдельную опциональную синхронизацию профилей. Текущие профили локальны и используют учётную запись Windows для защиты паролей.
- Стили Aurora покрывают собственные панели и элементы. Системные диалоги Windows, меню WebView2 на страницах и интерфейсы сайтов рисуются их владельцами.
