# Aurora 1.5.0

## Что работает

- Обычные и приватные вкладки, восстановление сеанса, загрузки, история, закладки и встроенные страницы.
- Перенос данных из найденных профилей Chromium и Firefox. Закладки и вкладки объединяются по адресу, посещения по адресу и времени. Файлы подкачки, cookie, активные авторизации и расширения исходного браузера не копируются.
- HTML-импорт закладок и CSV-импорт паролей HTTPS на Windows. Зашифрованное хранилище локально для пользователя Windows. Заполнение запускается вручную, для текущего сайта и подходящей формы входа.
- История с поиском по сохранённым посещениям и постраничной выдачей. До 50 000 последних посещений хранятся локально.
- Стеклянные панели, настраиваемые размытие и прозрачность, анимированный фон новой вкладки и плавное перетаскивание вкладок.
- Локальные плагины Aurora на CSS и JavaScript. Они включаются вручную и выполняются на посещаемых сайтах. Файлы плагина ограничены 512 КБ, папка должна находиться в каталоге плагинов Aurora.

## Что сделано для выпуска

- Добавлен раздел переноса с обнаружением профилей на Windows и ручным импортом файлов.
- Отключена реакция фона на курсор. Палитра, фотография и мягкие блики сохранены.
- Сокращена повторная обработка истории при переходах. Открывается только выбранная страница списка, остальные посещения доступны через поиск и пагинацию.
- Подготовлен репозиторий с MIT-лицензией и проверками форматирования, тестов, Clippy и сборки для Windows.

## Дальше

- Хранение истории на SQLite, чтобы обновлять отдельные записи по мере навигации.
- Сохранение структуры папок закладок и групп вкладок при переносе.
- Управление сохранёнными аккаунтами из интерфейса, расширение поддержки форм входа и проверка форматов экспорта разных версий браузеров.
- Настоящие расширения браузера и разграничение доступа по сайтам. Текущие локальные плагины имеют собственный формат.
- Больше проверок на больших профилях, низкомощной графике и разных масштабах экрана.
