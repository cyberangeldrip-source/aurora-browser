# Быстрый запуск Aurora на Windows

1. Запустите `target/release/bundle/nsis/Aurora_1.6.0_x64-setup.exe`.
2. После установки найдите Aurora через меню «Пуск».
3. Для запуска из папки проекта откройте `START-HERE.bat`.

Установщик рассчитан на Windows x64. Браузер проверялся на Windows 11. Если на компьютере нет WebView2 Runtime, установщик предложит его загрузить.

Если в папке остались только исходники, подготовьте Rust и C++ Build Tools по [инструкции по сборке](README.md#сборка-из-исходников). Затем запустите `START-HERE.bat` для сборки и запуска приложения или `INSTALL-AURORA.bat` для сборки установщика.
