# Aurora

Aurora — настольный браузер для Windows на Rust, Tauri 2 и Microsoft WebView2. Интерфейс и встроенные страницы поставляются вместе с приложением. Для запуска готовой сборки нужны только Windows и WebView2 Runtime.

## Запуск на Windows

- `target/release/bundle/nsis/Aurora_1.7.0_x64-setup.exe` устанавливает браузер для текущего пользователя. При необходимости установщик загружает WebView2 Runtime.
- `START-HERE.bat` запускает готовую сборку из папки проекта или собирает её из исходников.
- Сборка проверялась на Windows 11 x64. Установщик не подписан.

## Что работает

- У каждой открытой вкладки свой WebView2. При старте создаётся только активная вкладка, остальные загружаются при первом выборе. Уже открытые вкладки сохраняют своё состояние при переключении.
- Адресная строка и поиск на стартовой странице используют один механизм разбора адресов. Подсказки адресной строки берутся из локальной истории и закладок.
- Переходы назад и вперёд, остановка загрузки, повторное открытие закрытых вкладок, масштаб страницы, полноэкранное видео, загрузки и инструменты разработчика.
- Вкладки сжимаются по ширине ряда. Порядок можно менять мышью или клавишами, он сохраняется вместе с сеансом.
- Создавайте и переименовывайте группы через контекстное меню вкладки. Кнопка группы в ряду сворачивает её, оставляя активную вкладку видимой.
- На стартовой странице лента плавно движется и переливается. Переключатель «Живой фон новой вкладки» возвращает статичный фон.
- Панель закладок под адресной строкой показывает значки сайтов и папки. В разделе «Закладки» порядок меняется перетаскиванием или Alt+↑ и Alt+↓ на кнопке перемещения. Редактор переносит отдельные закладки и папки вместе с вложениями.
- Локальные профили Aurora открываются в отдельных окнах. История, вкладки, настройки, пароли, расширения и данные сайтов хранятся отдельно.
- В «Профили и пароли» можно искать сохранённые входы, добавлять, заменять и удалять записи. Хранилище защищено Windows DPAPI.
- Распакованные расширения WebView2 включаются из панели «Расширения». Папку с `manifest.json` можно добавить в разделе «Плагины». Для локальных CSS и JavaScript-плагинов можно задать список точных доменов, в том числе добавить текущий сайт кнопкой в редакторе.
- Стеклянная панель загрузок в Windows показывает прогресс и открывает папки файлов. Доступны пауза, возобновление и отмена. Список сохраняется для обычного сеанса.
- Закладки, поиск по истории, имена открытых вкладок и восстановление сеанса. Настройки и закладки можно переносить в JSON.
- Светлая и тёмная темы, цвет акцента, прозрачность панелей, сила размытия, анимации, компактная панель и её масштаб.
- Меню, подсказки и настройки открываются с прозрачностью. В Windows размытие и цветное преломление по нижнему краю используют кадр активной вкладки. Поздний кадр используется со следующего открытия. После закрытия кадр кратковременно остаётся в памяти для повторного открытия.
- Приватные вкладки используют режим InPrivate WebView2. Посещения не попадают в историю Aurora. Такие вкладки не входят в сохранённый сеанс или список закрытых. Загруженные файлы остаются на диске.

## Перенос данных

Откройте **Меню → Перенос данных**. На Windows Aurora ищет профили Brave, Chrome, Edge, Vivaldi, Яндекс Браузера, Chromium, Opera, Opera GX и Firefox в стандартных каталогах. Выберите профиль и нужные данные. Перенос добавляет записи к текущему профилю Aurora и показывает результат отдельно по каждой категории.

- Из Chromium-профилей читаются закладки, последние 50 000 посещений, сохранённые вкладки и до 150 записей журнала загрузок. Из Firefox читаются закладки, посещения и сохранённые вкладки.
- Для браузеров со штатным экспортом работают HTML-закладки и CSV-пароли. Пароли для HTTPS-сайтов хранятся с защитой Windows DPAPI. Откройте сайт и выберите аккаунт в разделе переноса, чтобы заполнить форму входа.
- Закройте исходный браузер, если его файлы заняты. Файлы загрузок остаются в исходных папках, журнал хранит их пути. Для авторизации на сайтах потребуется войти заново.
- Импорт Chromium и Firefox сохраняет пути закладок и метки групп вкладок. Для входа на сайты после переноса используйте импортированные пароли или ключи доступа исходного браузера.

Используйте [журнал разработки и план](PROJECT-STATUS.md), чтобы сверить текущие возможности и ограничения.

## Клавиатура

| Клавиши | Действие |
| --- | --- |
| Ctrl+L | Выделить адрес |
| Ctrl+T / Ctrl+W | Новая вкладка / закрыть вкладку |
| Ctrl+Shift+T | Восстановить закрытую вкладку |
| Ctrl+Shift+N | Приватная вкладка |
| Ctrl+Tab / Ctrl+Shift+Tab | Следующая / предыдущая вкладка |
| Alt+Shift+← / → в ряду вкладок | Передвинуть выбранную вкладку |
| Ctrl+1…9 | Вкладка по номеру, 9 — последняя |
| Alt+← / Alt+→ | Назад / вперёд |
| Ctrl+R или F5 | Обновить страницу |
| Ctrl+F | Поиск на странице WebView2 |
| Ctrl+«+» / «−» / «0» | Изменить / сбросить масштаб страницы |
| Ctrl+D / Ctrl+H / Ctrl+J | Закладки / история / загрузки |
| Ctrl+, / F11 / F12 | Настройки / полный экран / DevTools |

Средний клик по вкладке закрывает её. Колесо мыши прокручивает ряд вкладок по горизонтали.

## Данные и локальные плагины

Aurora хранит настройки, вкладки, историю и закладки в `%APPDATA%\dev.aurora.browser`. Существующие JSON-файлы подхватываются при запуске. Для тестового или отдельного профиля можно задать переменную окружения `AURORA_DATA_DIR`.

Локальные плагины расположены в подпапке `plugins`. Плагин содержит `manifest.json` и по желанию `style.css` и `script.js`. Новые плагины отключены по умолчанию. Включайте только код, которому доверяете, поскольку он может читать и изменять страницы. После изменения настроек плагина обновите вкладку. Некоторые сайты ограничивают внедрение стилей или скриптов своей политикой CSP.

## Сборка из исходников

Нужны Rust через Rustup с инструментарием MSVC, Visual Studio Build Tools с компонентом «Разработка классических приложений на C++» и Microsoft WebView2 Runtime.

```powershell
cargo test --locked
cargo run --locked
```

Сборка одного EXE:

```powershell
cargo build --release --locked --features custom-protocol
```

Сборка установщика NSIS:

```powershell
cargo install tauri-cli --version 2.12.6 --locked
cargo tauri build --ci --no-sign -- --locked
```
